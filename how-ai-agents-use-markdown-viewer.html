How an AI agent uses Markdown viewer

Read .md files as documents, including the ones your agent just wrote.

Updated 2026-10-09 · T3rnel Browser 1.3.0

What the agent can do

  • GitHub Flavored Markdown: tables, task lists, footnotes, strikethrough, autolinks.
  • Mermaid diagrams and LaTeX math rendered inline.
  • Sticky auto-generated table of contents with scroll-spy; light, dark and sepia themes.
  • Side-by-side diff between two Markdown documents.
  • Renders straight from the clipboard, which is the fastest way to read assistant output.
  • Sanitises strictly. Markdown is untrusted input, and a viewer with a scripting hole inside an extension is a serious problem — scripts, event-handler attributes and javascript: URLs are removed, and a payload corpus in the test suite proves it.

Questions

Which tools does Markdown viewer use?

browser_md_view, browser_md_diff.

Is Markdown viewer free?

Yes. Every tool listed here works on the free tier.

Does the agent have to ask before using Markdown viewer?

Each tool has a risk level: browser_md_view is low; browser_md_diff is low. The approval gate is off by default and can be armed in Settings.
