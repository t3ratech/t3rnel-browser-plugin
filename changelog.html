Changelog

1.3.0 24 September 2026 current

Added

  • Pay for Pro on the setup page. Choosing Pro at install now shows an email field, the payment methods the payment gateway currently takes, and a Pay button. Checkout opens in a tab and Pro turns on by itself on the setup page once the payment clears — no trip to the pricing site.
  • PayPal is back alongside PayNow in every chooser. The chooser shows exactly the methods the gateway reports at /v2/providers, so a method appears the moment the gateway can take it and is never offered while it cannot.
  • Free-tier prompts. Every fifth tool use on Free shows an in-panel prompt, alternating between an upgrade to Pro (with Pay and the payment chooser in the prompt) and a request for a store rating that links to the store this browser installs from. A Pro-only tool used on Free shows the upgrade prompt at once, naming the tool. Each prompt features one of T3raTech's other products. Pro users see none.
  • browser_viewport_set emulates a device or viewport through CDP, and browser_debugger_status reports who holds a debugger on each tab, with an optional attach→command→detach probe.
  • No-install Session Bridge. Point your MCP client at npx @t3ratech/mcp-session-bridge and the extension finds it on its own over a local WebSocket — no global install, no --install, no native host manifest. With AI/MCP automation allowed — the default — the first connection is approved automatically: no pairing prompt, and no per-action prompts ever. Arming the approval gate in Settings is what brings back a one-time pairing ask for new bridges. Native messaging still works as a fallback for older bridge installs. session_* errors for extension-only tools now say the extension is missing and link to where to get it.
  • Free or Pro, chosen on the install screen. The onboarding permissions screen offers both tiers side by side, and only shows what the choice needs: Free hides the optional-permission panel entirely; choosing Pro reveals it alongside an Activate card — paste a licence key and Pro turns on without leaving setup. The AI/MCP automation how-to collapses with its toggle.
  • Tools tab, rebuilt for humans. The pane now lists the tools a person would actually click — colour picker, full-page capture, page audit, PDF export, cache tools, recorder, inspector, form fill and clear, scroll guard, React detect, vault, diffing, codegen — and a tool that needs an argument asks for it by name instead of failing on a missing field. Agent plumbing (click, hover, wait and friends) no longer crowds the list; it all still runs over the bridge. Tools that need what only an agent holds — a request id, selector, coordinates or policy document — or that return data meant for a model (accessibility snapshot, compressed DOM) are left to MCP.
  • Growth surfaces in About. A Support section offers a share row — X, Facebook, LinkedIn, WhatsApp, Telegram, Reddit, Bluesky, Threads, Hacker News, Instagram, email and Copy link, each carrying the product site's link (the system share sheet did nothing on desktop Linux), a store rating link, a PayPal donate link, and a release-notes-by-email link — all outbound links, no new host access.
  • Prices come from the payment gateway. The Pro price and any launch offer are read from WavePay's /v2/pricing — the side panel, popup, Pro prompt, onboarding page, paywall message and docs site all show what checkout will charge, and wording without a figure when the gateway has not answered. No price is typed into the extension, its 24 translations or the site any more. A launch promotion, when one runs, takes a promo code at checkout; codes are minted in the WavePay console and never ship in the bundle.
  • Opt-in usage analytics. Local counters always record on-device and are shown in Settings. A toggle there shares anonymous aggregate counts — tool calls and days used, once a day — to T3raTech's own service, which forwards to Google Analytics 4. Off by default; nothing is sent while it is off; no page content, URL, argument or identity is ever included.

Fixed

  • Markdown files view again. The auto-viewer for .md/.markdown pages is repaired, and a file you open without file-access granted now shows a one-line instruction instead of raw text.
  • Toolbar icon on light themes. The icon was a white glyph on transparency — invisible on a light toolbar. It now carries a contrast plate that reads on both themes.
  • Upgrade permission hole. Updating from 1.1.x with the bridge already connected could leave it approved but unable to reach any page: the new-permissions prompt appeared, and host access was still missing afterwards. The first bridge connection after update now re-requests it with one click.
  • The perpetual test licence now works against the live licence service — the worker secret that enables it was never deployed. (TEST_LICENSE_KEY, test environments only.)

Changed

  • Approval gate defaults to off, and nothing asks twice. Installing the extension — or leaving "Allow AI/MCP automation" ticked at setup — is consent to use it: a connecting bridge is paired silently and every MCP action runs without a prompt. Declining the box arms the gate: new bridges get a one-time pairing card and page-changing actions stop and ask. The full gate — ask before page-changing actions, ask before everything — stays in Settings for anyone who wants it.
  • 97 tools, 94 over MCP. Removed browser_manifest_generate, browser_manifest_validate, browser_download_cancel, browser_color_history and browser_detect_editor; browser_license_collect, browser_license_recover and browser_license_release remain in the panel but no longer appear to MCP clients. The bridge therefore stays under client tool-count limits.

1.2.0 2 September 2026

Twenty-four languages, light and dark, and a stop to infinite scrolling.

Added

  • 24 languages. English, Mandarin Chinese, Hindi, Spanish, Standard Arabic, French, Bengali, Portuguese, Russian, Urdu, Indonesian, German, Japanese, Nigerian Pidgin, Egyptian Arabic, Marathi, Telugu, Vietnamese, Hausa, Swahili, Italian, Zulu, Shona and Ndebele. The panel picks your browser's language on first run; Settings has a picker if you want a different one. Arabic, Egyptian Arabic and Urdu lay the panel out right-to-left. Every language is complete — none falls back to English part-way through a screen.
  • Light and dark. Settings → Appearance. “Match the system” follows your machine; choosing Light or Dark stops it following, so your choice is not undone the next time your OS switches.
  • Stop infinite scrolling. A per-site toggle. Feeds that keep loading as you scroll stop at the end of what is already there, and a button appears to let one more batch through when you want it. The page's own loading code is never invoked rather than blocked mid-request, so turning it off leaves nothing half-finished.

Changed

  • Payments moved to T3rnel WavePay, the shared gateway behind every T3raTech product. Prices, the licence, the three-device limit and your existing licence key are unchanged, and nothing needs re-activating.
  • Checkout is PayNow, and now names what it takes: Visa, Mastercard, ZimSwitch, EcoCash, OneMoney, Telecash, InnBucks and O'mari, with the card marks drawn beside them. PayPal is no longer offered at checkout.

1.1.1 28 August 2026

Clear a form in one click.

Added

  • Clear form — empties every field in one click, from the panel or over MCP. Works on React and other framework-driven forms, keeps the hidden fields a page needs to submit, and leaves disabled fields alone.

Fixed

  • A reinstall no longer uses up one of your three Pro activations.
  • Fixed saving to the encrypted vault.
  • Fixed the approval queue showing a request waiting when none was.
  • Improved the run timeline, shadow testing, code export and DOM compression.
  • Improved the LLM firewall's per-site policies and secret masking.
  • Better compatibility with MCP clients.

1.1.0 27 August 2026

PayPal checkout, the MCP Session Bridge, and new tools.

Added

  • MCP Session Bridge: a free MCP server that exposes all 98 MCP tools over stdio. Install with npm install -g @t3ratech/mcp-session-bridge.
  • PayPal as a payment option at checkout, alongside PayNow.
  • Color picker with eyedropper, palette and history — copy any colour as hex, rgb(), hsl() or a ready --custom-property.
  • Clear cache and hard-reload tools for the current origin.
  • React debugging: component tree, props and hooks inspection.
  • Form filling that takes your own values: name a field by its name, its id or a CSS selector, and everything you do not name gets seeded test data.
  • CSS copy as a styled-components block, an Emotion css block, a CSS Modules class, SCSS, Less, or a JSX style object.
  • An About section in the side panel: version, contact, the free bridge, and the legal pages.

Fixed

  • Improved Pro activation, which now survives a permission re-prompt.
  • The panel shows what a tool produced, not just that it finished.
  • An approval policy set in Settings is now enforced everywhere.
  • Improved colour copying, screenshot capture, replay and page audit.

1.0.0 13 August 2026

First public release.

Added

  • CSS inspection with cascade walking, authored-unit preservation and multi-format copy.
  • Full-page screenshot engine with sticky-header pinning, lazy-load pre-scroll, animation freeze and cookie-banner dismissal.
  • Markdown viewer with GFM, Mermaid, LaTeX, themes, two-file diff and clipboard rendering.
  • Record, replay and export to Playwright, Puppeteer, Cypress and Selenium.
  • Agent safety suite: approval gate, credential redaction, prompt-injection flagging, DOM compression, delta snapshots, time-travel timeline.
  • Encrypted identity vault using AES-256-GCM.
  • Device-bound licensing with a three-installation limit.
  • Runtime permission broker: every optional permission is requested at first use with an explanation, and a denial returns a structured error instead of crashing.
