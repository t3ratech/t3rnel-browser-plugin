Changelog

1.4.0 7 November 2026 current

Added

  • Accounts. Sign in with a provider the panel offers; the provider's verified email identifies you. Pro now belongs to the person, not to one browser's key: sign in on up to five browsers, in any mix of browsers and machines, and the plan is there. Signing out, or being signed out from another browser in Settings, frees the seat; a seat unseen for 30 days is reclaimed when an account is full.
  • A monthly allowance for the free tools. A free account gets three uses a month of the free tools, counted by our service so that reinstalling or using a second browser does not reset it. The month is UTC and renews on the first. Pro tools stay Pro's: a free account is refused them by name and they never cost a use. Pro has no limit.
  • Sign-in first. Setup starts with sign-in before the package choice and the permissions. The side panel and popup show a sign-in gate until an account is signed in, and Settings has an Account section with the email, the seats and sign-out.
  • A licence key can be linked to your account from Settings, which files the licence under the account so every signed-in browser is Pro.
  • Usage analytics. One anonymous event per tool use and per button press — the tool or control, where it was used, how it ended, version, browser, plan — with no page content, address, argument, typed value or email. Firefox sends them only after you grant its technical-and-interaction data permission.
  • identity permission, used only to open the provider's sign-in page and receive its redirect. It carries no install warning, so updating does not disable the extension.

Changed

  • Every tool except browser_health, the licence tools and the status reads needs an account. A signed-out caller is told to sign in whatever the tool; a Pro licence key alone is not an account.
  • Pro keeps working offline on its fourteen-day entitlement plus the grace period. If the service cannot be reached, a free account fails closed and the tool does not run.
  • The usage-statistics switch is gone: analytics are part of the product. Firefox's manifest declares the verified email as required data and usage analytics as optional.
  • Recovering a key by email and releasing a device seat are replaced by the account: a purchase is found by the verified email, and a browser is signed out from Settings.
  • browser_license_check and the panel notes describe the free plan as three uses a month of the free tools, with the Pro tools Pro-only.

Fixed

  • The capability list a free account sees, the locked Pro tiles and the Pro notes in all 24 languages agree with what the tools enforce.

1.2.0 2 September 2026

Twenty-four languages, light and dark, and a stop to infinite scrolling.

Added

  • 24 languages. English, Mandarin Chinese, Hindi, Spanish, Standard Arabic, French, Bengali, Portuguese, Russian, Urdu, Indonesian, German, Japanese, Nigerian Pidgin, Egyptian Arabic, Marathi, Telugu, Vietnamese, Hausa, Swahili, Italian, Zulu, Shona and Ndebele. The panel picks your browser's language on first run; Settings has a picker if you want a different one. Arabic, Egyptian Arabic and Urdu lay the panel out right-to-left. Every language is complete — none falls back to English part-way through a screen.
  • Light and dark. Settings → Appearance. “Match the system” follows your machine; choosing Light or Dark stops it following, so your choice is not undone the next time your OS switches.
  • Stop infinite scrolling. A per-site toggle. Feeds that keep loading as you scroll stop at the end of what is already there, and a button appears to let one more batch through when you want it. The page's own loading code is never invoked rather than blocked mid-request, so turning it off leaves nothing half-finished.

Changed

  • Payments moved to T3rnel WavePay, the shared gateway behind every T3raTech product. Prices, the licence, the three-device limit and your existing licence key are unchanged, and nothing needs re-activating.
  • Checkout is PayNow, and now names what it takes: Visa, Mastercard, ZimSwitch, EcoCash, OneMoney, Telecash, InnBucks and O'mari, with the card marks drawn beside them. PayPal is no longer offered at checkout.

1.1.1 28 August 2026

Clear a form in one click.

Added

  • Clear form — empties every field in one click, from the panel or over MCP. Works on React and other framework-driven forms, keeps the hidden fields a page needs to submit, and leaves disabled fields alone.

Fixed

  • A reinstall no longer uses up one of your three Pro activations.
  • Fixed saving to the encrypted vault.
  • Fixed the approval queue showing a request waiting when none was.
  • Improved the run timeline, shadow testing, code export and DOM compression.
  • Improved the LLM firewall's per-site policies and secret masking.
  • Better compatibility with MCP clients.

1.1.0 27 August 2026

PayPal checkout, the MCP Session Bridge, and new tools.

Added

  • MCP Session Bridge: a free MCP server that exposes all 98 MCP tools over stdio. Install with npm install -g @t3ratech/mcp-session-bridge.
  • PayPal as a payment option at checkout, alongside PayNow.
  • Color picker with eyedropper, palette and history — copy any colour as hex, rgb(), hsl() or a ready --custom-property.
  • Clear cache and hard-reload tools for the current origin.
  • React debugging: component tree, props and hooks inspection.
  • Form filling that takes your own values: name a field by its name, its id or a CSS selector, and everything you do not name gets seeded test data.
  • CSS copy as a styled-components block, an Emotion css block, a CSS Modules class, SCSS, Less, or a JSX style object.
  • An About section in the side panel: version, contact, the free bridge, and the legal pages.

Fixed

  • Improved Pro activation, which now survives a permission re-prompt.
  • The panel shows what a tool produced, not just that it finished.
  • An approval policy set in Settings is now enforced everywhere.
  • Improved colour copying, screenshot capture, replay and page audit.

1.0.0 13 August 2026

First public release.

Added

  • CSS inspection with cascade walking, authored-unit preservation and multi-format copy.
  • Full-page screenshot engine with sticky-header pinning, lazy-load pre-scroll, animation freeze and cookie-banner dismissal.
  • Markdown viewer with GFM, Mermaid, LaTeX, themes, two-file diff and clipboard rendering.
  • Record, replay and export to Playwright, Puppeteer, Cypress and Selenium.
  • Agent safety suite: approval gate, credential redaction, prompt-injection flagging, DOM compression, delta snapshots, time-travel timeline.
  • Encrypted identity vault using AES-256-GCM.
  • Device-bound licensing with a three-installation limit.
  • Runtime permission broker: every optional permission is requested at first use with an explanation, and a denial returns a structured error instead of crashing.
