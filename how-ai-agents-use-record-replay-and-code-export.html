How an AI agent uses Record, replay and code export

Click through a flow once. Get a maintainable test that runs in your CI without this extension.

Updated 2026-10-09 · T3rnel Browser 1.3.0

What the agent can do

  • Generates ranked candidate selectors per element: data-testid beats id beats ARIA role plus accessible name beats a CSS path.
  • Scores each candidate for fragility — depth, index-dependence, hash-like class names — and warns inline when the best available option is brittle. That warning is the difference between a suite that survives a refactor and one that does not.
  • Exports to Playwright, Puppeteer, Cypress and Selenium.
  • Generated code waits on conditions. It never sleeps for a guessed number of milliseconds, and a test asserts that no waitForTimeout appears in the output.

Questions

Which tools does Record, replay and code export use?

browser_record_start, browser_record_stop, browser_record_list, browser_record_events, browser_record_replay, browser_codegen_start, browser_codegen_stop, browser_codegen_export, browser_codegen_status.

Is Record, replay and code export free?

Partly. browser_codegen_start, browser_codegen_stop, browser_codegen_export, browser_codegen_status need Pro ($29.99 once); browser_record_start, browser_record_stop, browser_record_list, browser_record_events, browser_record_replay work on the free tier.

Does the agent have to ask before using Record, replay and code export?

Each tool has a risk level: browser_record_start is low; browser_record_stop is low; browser_record_list is low; browser_record_events is low; browser_record_replay is high; browser_codegen_start is medium; browser_codegen_stop is medium; browser_codegen_export is low; browser_codegen_status is low. The approval gate is off by default and can be armed in Settings.
