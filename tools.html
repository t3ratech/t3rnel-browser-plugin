T3rnel MCP Session Bridge — 103 browser tools over stdio

The MCP Session Bridge is a free MCP server that exposes 103 browser-automation tools to Claude Code/Desktop, Cursor, VS Code, Windsurf, Antigravity, IntelliJ, Codex, Grok Build, Kimi Code/Desktop, JCode, Cline, OpenCode, Continue.dev, KiloCode, Roo Code, Aider, OpenClaw, Hermes, OpenFang and other MCP clients. In extension mode it drives the browser you are already signed into through the T3rnel Browser extension. In standalone mode it launches its own browser and needs no extension at all.

Your AI assistant can read the page you are already signed into, inspect CSS, capture screenshots, run audits, clear cache, fill forms, inspect React components and more — without a separate automation browser or re-authenticating.

The skill

Tools tell an agent what it can do. A skill tells it when — and, more usefully, when not to. signed-in-browser is published alongside the bridge and installs into any client that reads skills.

  • It says when not to use this. A public page should be fetched, not driven through somebody's live browser. Reaching into a real session for a page you could have requested is cost with no benefit.
  • It leads with the risk. This is a real browser logged into real accounts, so: read before you write, confirm anything irreversible in your own words first, and never enter a credential the model generated.
  • It says to verify. A click that resolves is not a click that worked. Re-snapshot and assert what changed — most silent automation failures are a selector that matched nothing and a caller that never looked.

On Smithery, or drop SKILL.md into ~/.claude/skills/signed-in-browser/.

Source and listings

The bridge is source-available at github.com/t3ratech/mcp-session-bridge — the same source the npm package ships. It is listed on npm, the official MCP registry as io.github.t3ratech/mcp-session-bridge, and Smithery. The extension itself is closed source and ships through the browser stores.

Add the MCP Session Bridge

One install, version-agnostic, no licence required for the bridge itself.

npm install -g @t3ratech/mcp-session-bridge
mcp-session-bridge --install

Configure your MCP client

{
  "mcpServers": {
    "t3rnel-session": {
      "command": "mcp-session-bridge",
      "env": { "T3RNEL_SESSION_MODE": "auto" }
    }
  }
}

Works with the T3rnel Browser extension

The bridge is free and works out of the box. For the full set of advanced tools and features, get the T3rnel Browser extension and upgrade to Pro. Pro is a one-time purchase that unlocks additional capabilities directly inside the extension.
