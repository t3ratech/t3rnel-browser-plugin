T3rnel MCP Session Bridge — 98 browser tools over stdio

The MCP Session Bridge is a free MCP server that exposes 98 browser-automation tools to Claude, Cursor, VS Code, Windsurf, Antigravity, IntelliJ and other MCP clients. In extension mode it drives the browser you are already signed into through the T3rnel Browser extension. In standalone mode it launches its own browser and needs no extension at all.

Your AI assistant can read the page you are already signed into, inspect CSS, capture screenshots, run audits, clear cache, fill forms, inspect React components and more — without a separate automation browser or re-authenticating.

Add the MCP Session Bridge

One install, version-agnostic, no licence required for the bridge itself.

npm install -g @t3ratech/mcp-session-bridge
mcp-session-bridge --install

Configure your MCP client

{
  "mcpServers": {
    "t3rnel-session": {
      "command": "mcp-session-bridge",
      "env": { "T3RNEL_SESSION_MODE": "auto" }
    }
  }
}

Works with the T3rnel Browser extension

The bridge is free and works out of the box. For the full set of advanced tools and features, get the T3rnel Browser extension and upgrade to Pro. Pro is a one-time purchase that unlocks additional capabilities directly inside the extension.

Risk tiers

Every tool carries a risk classification that drives the approval gate.

TierExamplesDefault behaviour for an MCP caller
LowReading a page, snapshots, CSS inspection, screenshots, navigationRuns
MediumClosing a tab, starting capture, editing styles liveRuns; gated when you set the policy to ask for everything
HighClicking, filling, typing, evaluating JavaScript, uploading, all vault operationsStops and asks

An unrecognised tool name is treated as high risk. Defaulting an unknown capability to "safe" is how a gate quietly stops being one.
